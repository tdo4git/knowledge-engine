# 🔥 NEW: Explainable Governance Decisions

Explainability is extended beyond retrieval to the **knowledge construction layer**.

This means:

- metadata classification decisions are traceable
- governance rules are explainable at field level
- every registry entry can be audited

Scope of explainability:

- origin classification
- document_type derivation
- knowledge_domain assignment

Key principle:

Explainability is generated **within the governance pipeline only**  
and is treated as a first-class architectural concern.
